# GeoSim — Frontend

React + Vite + deck.gl ile yazılmış harita arayüzü ve tarayıcıda çalışan trafik simülasyonu.
Kurulum ve çalıştırma adımları için projenin kök dizinindeki `README.md` dosyasına bakın.

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # simülasyon ve düzenleme testleri
```
